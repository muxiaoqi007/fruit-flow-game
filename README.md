# Fruit Flow / 果流实验室

一款以半流体物理为核心的水果合成 HTML 游戏。水果会在落地和受压时摊软、鼓出与回弹；两颗相同水果碰撞后进化为更高级水果，直到容器装满。

## 在线试玩

[https://fruit-flow-game.pages.dev/](https://fruit-flow-game.pages.dev/)

## 玩法

- 移动鼠标或手指瞄准，点击或松手投下水果
- 两颗相同水果碰撞后自动进化并累计得分
- 2.8 秒内连续合成可获得连锁奖励
- 使用“换一颗”调整待投水果
- 使用“晃一晃”或按住“液化”重新整理果堆
- 水果持续越过满载线 2 秒后结算

键盘支持方向键瞄准、回车投放、`X` 换果、`S` 晃动、空格液化、`P` 暂停。

## 本地运行

```bash
python3 -m http.server 8765
```

打开 [http://localhost:8765](http://localhost:8765)。游戏不依赖第三方库，也可以直接打开 `index.html`。

## 测试

```bash
node --test tests/game.test.cjs
```

测试覆盖合成进化、累计计分、连锁奖励、换果、晃动、液化、满载结算、软体边界和移动端触控映射。

## 技术特点

- 单文件 Canvas 游戏，无运行时依赖
- 面积近似守恒的半流体形变与软体碰撞
- 桌面、手机竖屏、手机横屏和平板响应式布局
- 本地保存最高分

## 揉揉 / Squish Club — 3D 软体互动玩具

新增独立游戏入口：[揉揉](./squishy/)。本地启动服务后访问 `http://localhost:8765/squishy/`，原水果游戏仍在首页。

根据参考形象制作的红色小红，包含奶油色脸、紫色比心手套与眼神跟随：

- **人物切换**：顶部选择小红或小青；小青采用独立青色身体、橙色内衬翻卷、深蓝手脚与五官，整个模型共同参与形变。记住上次选择，切换时清除旧抓取和挑战状态
- **手机全屏揉捏**：首页保留人物、常用工具和角色切换；软糯程度、音色、力度及额外玩法收进“玩法与设置”底部面板。选择玩法后面板自动收起，支持窄屏、横屏和安全区域

- **揉一揉**：按住让整个身体压扁并向两侧鼓胀，拖动可以揉歪、扯出局部形变；最大力度约压到原高度的三分之一，再松手软弹复原
- **拉一拉**：抓住身体向任意方向拉长，受拉位置局部收细、脚部保持支撑，松手惯性回弹
- **转一转**：拖动查看 3D 侧面和背面，双击回正面
- **捏扁它**：持续的掌心挤压演示；支持空格键
- **按压力度**：10%–100% 连续调节，另有轻轻捏 / 普通捏 / 用力捏三个预设；压力越高，凹陷更深、接触范围更广
- **实时压感**：支持 PointerEvent 压感的触笔 / 触屏随压力变化；普通触屏和鼠标按住 1.65 秒逐渐加力，压感表显示本次实际施加的力度
- **软糯程度**：调整弹性与恢复速度
- **揉捏声音**：软胶摩擦 / 啵啵气泡 / Q 弹三种可切换音色，力度与移动速度驱动音量、摩擦音、音高；松手独立回弹声。默认开启，在首次触摸后解锁，可一键静音
- **重新蓬松**：恢复模型、视角及物理状态
- **五点触控**：最多五根手指分别抓住身体，每指独立压感、拉扯；两指靠近挤压、分开拉伸或绕转扭动。松开任意一指，其余抓取继续保留，彩色编号标记显示接触位置
- **拍一拍 / 抖一抖 / 拧麻花**：轻点身体产生弹性波动，也可用按钮触发拍打、摇晃或扭转；快捷键 `4` / `5` / `6`
- **变形挑战**：不计时，依次完成捏扁、拉长、扭动，并短暂保持形状；完成后庆祝，可重新挑战
- **挠痒痒**：点击顶部模式，按住肚子来回摩擦，触发眯眼、张嘴、躲闪与抖动；小红、小青有不同音高的合成卡通笑声，停止后逐渐平静
- **不倒翁**：拖动推歪身体，松手后依靠恢复力和阻尼来回摇摆直至站稳；配合轻碰与回摆弹响。点击揉一揉可回到软体揉捏
- 支持鼠标和手机触摸。快捷键 `1` / `2` / `3` 切换工具，`R` 复原。

实现采用 Three.js 0.170.0（随项目附带，MIT）、693 节点局部三维弹簧网格及降阶黏弹性大形变模型。沿挤压方向压缩、自由方向鼓胀，压缩张量行列式为 1；拖动额外产生局部拉长与收细，松手通过二阶阻尼弹簧恢复。身体与五官经过同一个连续映射共同形变，抓取点从受力网格反算回初始坐标。声音使用 Web Audio 实时合成，包含滤波噪声摩擦层、变调共振和回弹瞬态，不需要下载音频。这是面向实时互动的软体近似，并非严格体积守恒的有限元材料模拟。纹理与几何均程序生成，不依赖外部资源。需要支持 WebGL 2 的浏览器，并通过 HTTP 服务访问。

物理、压感和多点手势检查：`node --test tests/squishy.test.mjs tests/pressure.test.mjs tests/gel.test.mjs tests/gestures.test.mjs`。

交互参考：[奶龙捏捏的压缩、拉伸与回弹示例](https://bearhugs.in/products/nailong-milk-dragon-squishy-toy)。保留小红形象，参考玩具的大幅挤压、拉伸和回弹行为。


## 墨水吞噬 / INK FLOW

在线试玩：[墨水吞噬](https://fruit-flow-game.pages.dev/ink-flow/)。

本地入口：[墨水吞噬](./ink-flow/)。启动上面的本地 HTTP 服务后，访问 `http://localhost:8765/ink-flow/`。

- 鼠标移动或触屏拖动控制青绿色墨水，WASD / 方向键也可移动。
- 按住水面、旋涡按钮或空格吸引附近墨滴；旋涡也会吸引污染物。
- 点击冲刺或按 Shift 消耗 25 能量，短暂冲刺可击碎珊瑚色污染物，冷却 3 秒。
- 每吸收 15 滴进化一次，共五种形态；连续吸收增加分数。
- 污染物降低纯净度，吸收墨滴恢复纯净度；纯净度耗尽或 3 分钟结束时结算。
- 支持暂停、失焦自动暂停、重新开始、可选合成音效及本地最佳成绩。

采用 Canvas 2D 有机形变、透明颜料拖尾和旋涡粒子近似流体观感，无第三方运行依赖；并非完整流体方程求解器。

逻辑验证：`node --test tests/ink-flow.test.mjs`。


## 液体弹珠台 / AQUA PINBALL

本地入口：[液体弹珠台](./liquid-pinball/)。启动 HTTP 服务后打开 `/liquid-pinball/`。

- 每局五次发射，水团全部离开台面后可发射下一滴。开始自动发射第一滴。
- 左右方向键 / A、D、下方左右挡板按钮，或直接触摸台面左右半区控制挡板；支持双指同时控制。
- 空格发射，J 使用上升喷流（7 秒冷却），P 暂停；页面失焦自动暂停。
- 撞击机关得分，3 秒内连续撞击叠加倍率，最多 5 倍。水团从上方落入金色容器获得 500 分。
- 较大的水团撞击机关会分裂，速度接近的水滴接触时融合，保持二维面积。水花粒子是装饰效果。
- Canvas 2D 渲染形变、透明拖尾与水花；圆形碰撞体与运动挡板近似液体弹珠物理，并非完整流体模拟。
- 本地保存最高分，可开启合成音效。

测试：`node --test tests/liquid-pinball.test.mjs`。
